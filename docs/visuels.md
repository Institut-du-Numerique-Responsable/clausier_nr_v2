# Visuels de présentation

Générés par `make visuels` dans `dist/visuels/`, en PNG et en WebP (plus léger : à privilégier
dans WordPress). Ce sont des rendus des vrais livrables, sans retouche. Dans le classeur,
trois clauses sont retenues à titre d'exemple : COM-Q-13, CLD-Q-01, DEV-E-04.

Textes alternatifs proposés pour WordPress :

| Fichier | Texte alternatif |
|---|---|
| `pdf-v2-page-de-garde` | Page de garde du Clausier Numérique Responsable, version 2.0, août 2026 |
| `pdf-v2-page-de-garde-vignette` | Couverture du Clausier Numérique Responsable V2 |
| `pdf-v2-page-08-questionnaire` | Page du clausier : questionnaire d'évaluation des soumissionnaires, exigences communes, avec niveaux Must have et Nice to have |
| `excel-presentation` | Classeur Excel du clausier, feuille Présentation : mode d'emploi et licence |
| `excel-catalogue` | Classeur Excel, feuille Catalogue : identifiant, critère, commentaire, questions, niveaux 1 et 2 de chaque clause |
| `excel-selection` | Classeur Excel, feuille Sélection : colonne Retenir à remplir par Oui pour chaque clause utile |
| `excel-clauses-retenues` | Classeur Excel, feuille Clauses retenues : texte complet des clauses choisies, regroupé automatiquement |
| `site-accueil` | Site du clausier : accueil avec le nombre de clauses par segment d'achat et par partie |
| `site-accueil-mobile` | Site du clausier sur téléphone |
| `site-catalogue` | Site du clausier : catalogue filtrable des 102 clauses |
| `site-fiche-clause` | Site du clausier : fiche d'une clause, niveaux 1 et 2 côte à côte |
