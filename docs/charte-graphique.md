# Charte graphique du site

Relevé effectué le 19 octobre 2026 sur la feuille de style publique d'institutnr.org (thème
WordPress « ascension »). Ce relevé n'est pas une charte officielle de l'INR : il est à
valider par l'INR.

## Couleurs reprises

| Rôle sur le site | Valeur | Variable relevée sur institutnr.org |
|---|---|---|
| Titres, liens, boutons, niveau 1, pied de page | `#194f6e` | `--ascension-blue` |
| Texte courant | `#173b4f` | `--ascension-ink` |
| Niveau 2, sélection, focus | `#147d78` | `--ascension-teal` |
| Texte secondaire | `#55707e` | `--ascension-muted` |
| Fonds de bloc | `#f4f8f8` | `--ascension-surface` |
| Filets | `#d8e3e6` | `--ascension-border` |

Rayons : 0,5 rem (blocs), 0,35 rem (boutons), comme sur institutnr.org. Pied de page sur
fond bleu, comme sur institutnr.org.

## Différences assumées

| Élément | institutnr.org | Site du clausier | Motif |
|---|---|---|---|
| Polices | Open Sans, Inter, Montserrat (téléchargées) | Police système | Aucun téléchargement de police (sobriété) |
| Logo | `INR-logo-s.jpg` | Nom en texte | Conditions d'utilisation du logo INR et du logo FTCC non établies ; à ajouter après accord |
| Bandeau cookies | Complianz | Aucun | Le site ne dépose aucun cookie |
| Navigation | Menu de l'INR | Menu propre au clausier, lien vers institutnr.org en pied de page | Site autonome |

## Contraste

Toutes les associations texte/fond utilisées dépassent le ratio 4,5:1 du RGAA pour le texte
courant (`#173b4f`, `#194f6e`, `#147d78` et `#55707e` sur blanc ; blanc sur `#194f6e`).
À confirmer lors de l'audit d'accessibilité.
