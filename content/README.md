# Contenu éditorial

Source de référence du clausier. Voir `docs/modele-documentaire.md`.

- `clauses/<segment>/<ID>.md` : une clause par fichier (texte du V2).
- `segments/` : textes de section de chaque segment (V2) ; les marqueurs
  `<!-- clauses section="…" -->` placent la liste des clauses sur le site.
- `pages/` : pages du V2 hors clauses. Texte d'origine, coquilles comprises.
- `site/` : pages rédigées pour le site, hors V2.
