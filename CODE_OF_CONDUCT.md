# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/),
dont la traduction française fait foi pour les échanges de ce dépôt.

En résumé : échanges courtois et argumentés, critique des idées et non des personnes,
respect de la diversité des organisations contributrices, publiques comme privées.

Pour signaler un comportement contraire à ce code : `contact@institutnr.org`. Les signalements sont traités de façon confidentielle par
les mainteneurs désignés par l'INR.
